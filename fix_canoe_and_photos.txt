PART 3 — FIX MISSING CANOE RIDE (src/lib/routing.ts)
================================================================================

The canoe logic inside buildSmartRoute only fires when going from a southern
village (samoa/tonga) to a northern village (tahiti/hawaii/aotearoa). But with
the new slot-based engine, lastVillage may be null or a middle village when the
northern slot comes up, so the canoe never triggers.

Fix: expand the canoe trigger condition so it fires whenever we are NOT already
in a northern village and the target village IS northern, regardless of what
lastVillage is. Also add a return canoe at the end if the guest ends in a
northern village.

Find this block inside buildSmartRoute (inside the "for (const targetMin of targetHours)" loop):

    if (bestVillage && bestShow) {
      // Insert canoe if needed to reach northern villages
      const needsCanoe = !canoeUsed &&
        ['tahiti', 'hawaii', 'aotearoa'].includes(bestVillage) &&
        ['samoa', 'tonga'].includes(lastVillage ?? '');
      if (needsCanoe) {
        const canoeMin = getNextCanoeTime(curMin, 'north');
        if (canoeMin && canoeMin + TIMING.CANOE_DURATION_MIN <= bestShow.timeMin) {
          addStop(buildCanoeStop(canoeMin, 'north'));
        }
      }

      addStop(buildShowStop(
        bestVillage, bestShow.name, bestShow.time,
        isBusy, usedVillages, interests, energy, group
      ));
    }

Replace with:

    if (bestVillage && bestShow) {
      const isNorthernVillage = ['tahiti', 'hawaii', 'aotearoa'].includes(bestVillage);
      const currentlyInNorth  = ['tahiti', 'hawaii', 'aotearoa'].includes(lastVillage ?? '');

      // Insert northbound canoe if heading into northern villages for the first time
      if (!canoeUsed && isNorthernVillage && !currentlyInNorth) {
